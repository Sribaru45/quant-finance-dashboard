PURPOSE OF THIS FILE
--------------------
This document defines every visual and UX decision in the platform. It is
designed to be loaded into Claude (or any AI assistant) to rebuild, extend, or
redesign the UI without needing to inspect the code. All CSS, layout rules,
component patterns, and chart standards are recorded here.


DESIGN PHILOSOPHY
-----------------
Aesthetic:    Bloomberg terminal meets modern dark UI — dense, data-first,
              professional. No decorative elements. Every pixel earns its place.
Audience:     Capital markets recruiters, risk analysts, quant PMs. The UI
              should communicate technical credibility at a glance.
Tone:         Serious, precise, minimal. No gradients except the module header
              banner. No rounded corners beyond 8px. No animations except
              card hover transitions.
Framework:    Streamlit 1.45.1 with custom CSS injected via st.markdown()
              unsafe_allow_html=True. All styles live in utils/styling.py.
              Global CSS is applied on every page via apply_global_css(st).

PAGE LAYOUT
-----------
All module pages follow a strict 70/30 two-column split:
  col_main, col_params = st.columns([7, 3])
  - col_main (70%):   Analysis output — charts, tables, results, metrics
  - col_params (30%): Parameters panel — all user inputs, sliders, selects

Navigation:
  - st.navigation() with sidebar_left=True
  - Pages registered in app.py in this order:
      Home, Credit Risk, Risk Analytics, Options Pricing,
      Portfolio Optimization, Pairs Trading, Value Investing
  - Streamlit branding hidden (#MainMenu, footer, header all visibility:hidden)

Sidebar footer (every page):
  - Fixed to bottom of sidebar
  - "Built by Sriram Bharadwaj | GitHub | LinkedIn"
  - Called via sidebar_footer(st) from utils/styling.py


COMPONENTS
----------

1. MODULE HEADER BANNER
   Used at the top of every module page.
   Called via: module_header(st, icon, title, description)

   Visual spec:
   - Background: linear-gradient(90deg, #1C1C2E 0%, #0E1117 100%)
   - Left border: 4px solid #00D4AA
   - Border radius: 0 6px 6px 0 (only right side rounded)

   - Margin bottom: 1.5rem

   - Subtitle: 0.9rem, #A0AEC0

   Example usage:
     module_header(st, "📉", "Credit Risk Model", "PD / LGD / Expected Loss")

   Streamlit st.metric() components, styled via CSS targeting stMetric.

   Visual spec:
   - Background: #1C1C2E
   - Border: 1px solid #2D2D44
   - Border radius: 8px
   - Padding: 12px 16px
   - Value: 1.4rem, font-weight 700, #00D4AA
   - Label: 0.75rem, uppercase, letter-spacing 0.05em, #A0AEC0
   - Delta arrow SVG hidden (display:none)

3. MODULE CARDS (Home page only)
   Clickable cards in the home page module grid.

   Visual spec:
   - Background: #1C1C2E
   - Border: 1px solid #2D2D44 (default) → #00D4AA on hover
   - Border radius: 8px
   - Padding: 1rem 1.25rem
   - Margin bottom: 0.75rem
   - Transition: border-color 0.2s
   - Heading: 0.95rem, #00D4AA
   - Body: 0.82rem, #A0AEC0

4. ERROR CARD

   Called via: error_card(st, message, suggestion="")

   Visual spec:
   - Background: #2D1C1C

   - Border radius: 8px
   - Padding: 1rem 1.25rem
   - "Error:" label in #FF6B6B bold

   Visual spec:

   - Text color: #0E1117 (dark on teal)

6. INPUT LABELS
   All st.selectbox, st.slider, st.number_input, st.text_input labels.

   Visual spec:

CHART STANDARDS
---------------
All charts use Plotly. The global layout dict is defined in utils/styling.py
as PLOTLY_LAYOUT and must be spread into every fig.update_layout() call:
  fig.update_layout(**PLOTLY_LAYOUT)

PLOTLY_LAYOUT spec:
  template:       "plotly_dark"
  paper_bgcolor:  "#0E1117"
  plot_bgcolor:   "#0E1117"
  font:           color="#FFFFFF", family="Courier New"
  title_font:     color="#FFFFFF", size=16
  legend:         bgcolor="#1C1C2E", bordercolor="#2D2D44", borderwidth=1
  margin:         l=40, r=20, t=50, b=40

Chart color usage:
  - Primary series:   #00D4AA (teal accent)
  - Danger/loss:      #FF6B6B (red)
  - Neutral/secondary: #A0AEC0 (subtext grey)
  - Additional series: use Plotly dark palette defaults

Chart types used per module:
  Home:             Line chart (SPY price)
  Credit Risk:      Gauge (risk score), Bar (feature importance),
                    Histogram (PD distribution)
  Risk Analytics:   Histogram (return distribution), Line fan (Monte Carlo),
                    Line (cumulative returns)
  Options Pricing:  Bar (Greeks), Line (Delta+Price vs Spot),
                    Heatmap x2 (Price×Vol, Delta×Vol)
  Portfolio Opt:    Scatter (efficient frontier), Bar (weights)
  Pairs Trading:    Line+scatter (z-score with trade markers), Line (P&L)
  Value Investing:  Line (cumulative returns), Bar x2 (weights, individual returns)


STREAMLIT CONFIG
----------------
Streamlit's own UI chrome is hidden on all pages:
  #MainMenu { visibility: hidden; }
  footer     { visibility: hidden; }
  header     { visibility: hidden; }

This is applied globally in GLOBAL_CSS, injected on every page load.


HOW TO APPLY THE DESIGN SYSTEM
--------------------------------
Every page must do the following at the top:

  import streamlit as st
  from utils.styling import apply_global_css, module_header, error_card, sidebar_footer, PLOTLY_LAYOUT

  apply_global_css(st)                              # inject all CSS
  module_header(st, "🔣", "Page Title", "Subtitle") # top banner
  # ... page content ...
  sidebar_footer(st)                                 # bottom of sidebar

All charts:
  fig = go.Figure(...)
  fig.update_layout(**PLOTLY_LAYOUT, title="Chart Title")
  st.plotly_chart(fig, use_container_width=True)
