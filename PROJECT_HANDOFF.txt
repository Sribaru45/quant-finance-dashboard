THE 6 MODULES
-------------

1. CREDIT RISK MODEL (pages/credit_risk.py)
   - Logistic regression PD model
   - Market toggle: US (FICO 300-850) | India (CIBIL 300-900) | German (UCI dataset)
   - Outputs: PD score, risk tier (Low/Medium/High), Expected Loss = PD x LGD x EAD
   - Charts: risk gauge, feature importance bar chart, population PD distribution
   - Basel II/III framing throughout
   - Downloadable mini-report

2. RISK ANALYTICS (pages/risk_analytics.py)
   - Historical VaR, Parametric VaR, Monte Carlo VaR (up to 10,000 paths)
   - CVaR (Expected Shortfall) for all three methods
   - Multi-ticker via st.multiselect (searchable, from Alpaca asset list)
   - Charts: return distribution histogram, Monte Carlo fan chart, cumulative returns
   - Normality assumption disclaimer on parametric method
   - Downloadable mini-report

3. OPTIONS PRICING (pages/options_pricing.py)
   - Black-Scholes for European calls and puts
   - Full Greeks: Delta, Gamma, Theta, Vega, Rho
   - Charts: Greeks bar chart, Delta+Price vs Spot, 2 heatmaps (Price x Vol, Delta x Vol)
   - Moneyness, intrinsic value, time value displayed
   - Downloadable mini-report

4. PORTFOLIO OPTIMIZATION (pages/portfolio_opt.py)
   - Markowitz mean-variance, efficient frontier via random portfolio sampling
   - Sharpe maximization via scipy.optimize.minimize
   - Toggle: long-only (weights >= 0) vs allow short selling
   - Multi-ticker via st.multiselect (searchable)
   - Charts: efficient frontier scatter, weight bar chart
   - Shows both Max Sharpe and Min Volatility portfolios
   - Downloadable mini-report

5. PAIRS TRADING BACKTEST (pages/pairs_trading.py)
   - Engle-Granger cointegration (ADF test via statsmodels)
   - Z-score based entry/exit signals with configurable thresholds
   - Full P&L backtest engine with transaction costs
   - Trade markers on z-score chart
   - Metrics: trade count, win rate, Sharpe, avg win/loss
   - SQLite persistence: save button writes to data/backtests.db
   - History table with delete-by-ID and Refresh button
   - In-sample disclaimer shown
   - Downloadable mini-report
   - Tickers: two st.selectbox dropdowns (searchable)

6. VALUE INVESTING SCREENER (pages/value_investing.py)
   - Buffett-style fundamental filters (13 sliders):
     Valuation: P/E, P/B, PEG, EV/EBITDA
     Profitability: ROE, ROA, Gross Margin, Net Margin
     Health: Debt/Equity, Current Ratio
     Growth: Revenue Growth, EPS Growth
     Dividends: Dividend Yield
   - Composite Value Score ranks passing stocks
   - Portfolio builder from passing stocks (st.multiselect)
   - Side-by-side: Equal-Weight vs Markowitz-Optimized allocation
   - Performance comparison: return, vol, Sharpe, max drawdown
   - Timeframe selector (1mo to 3y)
   - Charts: cumulative return comparison, weight bar charts, individual stock returns
   - Fundamentals via yfinance .info (unreliable — known issue, see bugs)
   - Downloadable mini-report

HOME PAGE (pages/home.py)
   - Live SPY, QQQ, GLD price metrics with 1-day delta (fetches 1mo data)
   - SPY price chart
   - Module grid with clickable st.page_link() cards


KNOWN BUGS / ISSUES
-------------------

1. [HIGH] Value Investing Screener fundamentals unreliable
   - Uses yfinance .info which fails frequently
   - P/E, ROE, Debt/Equity often return None → shows N/A
   - Fix: Replace with Financial Modeling Prep (FMP) free API
   - FMP signup: financialmodelingprep.com (free tier: 250 calls/day)

2. [HIGH] Backtest save button unreliable in some sessions
   - Root cause: st.rerun() was interrupting save_backtest() before SQLite commit
   - Current fix: direct save_backtest() call in button handler + Refresh button
   - If still broken: check data/backtests.db row count via:
     sqlite3 data/backtests.db "SELECT COUNT(*) FROM pairs_backtests;"

3. [MEDIUM] Alpaca IEX feed missing some tickers
   - IEX is a subset of all US equities
   - Some smaller/OTC tickers return empty data → falls back to synthetic
   - Fix: use SIP feed (requires Alpaca paid plan) or filter asset list to IEX-only tickers

4. [MEDIUM] Home page metrics show N/A on first load sometimes
   - Happens when Alpaca returns only 1 bar (not enough for delta calc)
   - Fetches 1mo data now to ensure >= 2 bars — should be resolved
   - If still happening: check Alpaca API key is valid

5. [LOW] financial_dashboard.py still exists in pages/ but is not registered
   in navigation. Keep it as reference, do not delete.

6. [LOW] No loading spinner when fetching ticker dropdown list
   - fetch_asset_list() can take 2-3 seconds on first load
   - Cached for 24 hours after first fetch
